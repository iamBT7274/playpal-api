Endpoints
All endpoints return JSON. No authentication required. CORS enabled.
GET /v1/games.json All games with metadata

Returns every game in the database along with API metadata, statistics, and available categories/regions.

Example
fetch('https://iamBT7274.github.io/playpal-api/v1/games.json')
  .then(res => res.json())
  .then(data => console.log(data.games));
GET /v1/stats.json Statistics & metadata only

Lightweight endpoint returning only stats: game counts by region, by category, and available filter values.

GET /v1/regions/{region}.json Games from a specific region

Returns all games from a given region. Region names are lowercase with hyphens.

afghanistanbangladeshbhutan indiamaldivesnepal pakistansri-lanka
Example
fetch('https://iamBT7274.github.io/playpal-api/v1/regions/india.json')
  .then(res => res.json())
  .then(data => console.log(data.games));
GET /v1/categories/{category}.json Games by category

Returns all games in a specific category.

boardperformancephysical recreationalseasonalskill strategy
GET /v1/game/{id}.json Single game by ID

Returns full details for one game using its document ID.

Example
fetch('https://iamBT7274.github.io/playpal-api/v1/game/afg_buzkashi_001.json')
  .then(res => res.json())
  .then(data => console.log(data.game));
Game Object Schema
Each game object contains the following fields.
FieldTypeDescription
idstringUnique identifier
titlestringGame name
descriptionstringDetailed description of the game
regionstringCountry / region of origin
locationstringSpecific location within the region
imageUrlstringURL to the game's image
categorystringGame category (Physical, Strategy, Board, etc.)
intensitystringPhysical intensity level (Low, Medium, High)
playersstringNumber of players required
occasionstringWhen the game is typically played
tagsstring[]Descriptive tags
equipmentstring[]Equipment needed to play
howToPlaystring[]Step-by-step instructions
ratingnumberAverage user rating (0–5)
viewsnumberTotal view count
likesnumberTotal likes
reviewCountnumberNumber of reviews
createdAtstringISO 8601 timestamp
Quick Start Examples
Use from any language or framework — no API key, no signup.

JavaScript (Browser / Node)

JS
const BASE = 'https://iamBT7274.github.io/playpal-api/v1';

// Get all games
const all = await fetch(`${BASE}/games.json`).then(r => r.json());

// Filter by region
const indian = await fetch(`${BASE}/regions/india.json`).then(r => r.json());

// Get a single game
const game = await fetch(`${BASE}/game/afg_buzkashi_001.json`).then(r => r.json());

Python

Python
import requests

BASE = "https://iamBT7274.github.io/playpal-api/v1"

# Get all games
data = requests.get(f"{BASE}/games.json").json()
for game in data["games"]:
    print(game["title"], "-", game["region"])

How to Host This API
Deploy on GitHub Pages in 5 minutes — free forever.

Create a new GitHub repository

Go to github.com → New Repository → name it playpal-api → Public → Create

Push the api folder

From your playpal/api folder, run the git commands shown below to push everything.

Enable GitHub Pages

Go to repo Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder: / (root) → Save

Access your API

Your API will be live at https://iamBT7274.github.io/playpal-api/v1/games.json within a few minutes!
